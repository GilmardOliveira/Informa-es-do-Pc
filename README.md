# 🖥️ Informações do PC com Python

Projeto desenvolvido para praticar Python e consultar informações de hardware de um computador com Windows utilizando a biblioteca WMI.

## 📌 Sobre o projeto

O script coleta e exibe informações básicas do computador, como fabricante, modelo, nome da máquina, quantidade de processadores lógicos reportada pelo sistema, arquitetura e família do equipamento.

## 🛠️ Tecnologias utilizadas

* Python 3
* Biblioteca `WMI`
* Windows Management Instrumentation (WMI)

## ⚙️ Requisitos

* Windows com suporte a WMI
* Python 3 instalado

## ▶️ Como executar

Instale a dependência:

```bash
python -m pip install WMI
```

Execute o script:

```bash
python informacoesPc.py
```

## 🎯 Objetivo

Praticar programação Python e aprender a consultar informações do sistema operacional, com foco em administração de computadores e infraestrutura de TI.

## 🚀 Melhorias futuras

* Coleta de informações do processador e memória RAM
* Informações sobre discos e armazenamento
* Exportação dos dados para CSV
* Tratamento de erros e organização do código
